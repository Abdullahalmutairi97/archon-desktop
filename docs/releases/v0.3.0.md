## Reconstruct and verify

The private frozen parent is intentionally not committed. With Node.js 22.12+ and npm:

```bash
npm run setup
export ARCHON_V030_ASAR=/path/to/app-v0.3.0-unified-refresh.asar
npm test
npm run build:candidate -- "$ARCHON_V030_ASAR" /tmp/archon-v030-candidate.asar
npm run test:backend
git diff --check
```

The builder validates the parent hash and package version, applies guarded substitutions, bundles PeerJS 1.5.4, validates the renderer syntax, and refuses to overwrite an existing output. It does not install or restart the app.

The preview is disposable and uses synthetic data:

```bash
node current/testing/preview.cjs "$ARCHON_V030_ASAR"
```

Open `http://127.0.0.1:4318`; never enter production credentials in the preview. See the [candidate ledger](v0.3.0-candidate.md) and [release checklist](../releases.md).
