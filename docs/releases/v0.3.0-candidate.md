## Current behavior

- `current/candidate.cjs` validates the frozen parent, applies guarded patches, bundles PeerJS 1.5.4, permits its signaling socket, checks the renderer syntax, and writes a candidate ASAR.
- The IDE extracts code and file paths from the selected transcript, provides explorer/tabs/line numbers, and supports copy, reload, edit, save, terminal access, and dirty-close protection.
- Codex appears in the agent list and runs locally through its adapter. It does not require a backend change.
- Sharing lets the user review a session or project snapshot and create a PeerJS invite or explicit offline code. Shared data is read-only; files, credentials, tool/thinking records, live editing, agent control, and team membership are excluded.
- Connection settings accept the device token through the existing write-only desktop bridge and test authenticated status.
